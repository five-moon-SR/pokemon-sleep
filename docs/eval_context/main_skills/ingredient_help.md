### 仕様メモ・実測発動確率
Wiki「ヤミカラス」ページに記載の実測値（サンプル1000件、検証記事: https://pokesuri.ogagawa.com/kyouun_kenshou/ ）:

| 抽選結果 | 実測割合 |
|---|---:|
| あじわいキノコ | 21.13% |
| マメミート | 22.04% |
| ワカクサ大豆 | 19.28% |
| めざましコーヒー | 21.74% |
| ゆめのかけら（小） | 13.08% |
| ゆめのかけら（大） | 2.72% |
| 食材カテゴリ計 | 84.20% |
| ゆめのかけらカテゴリ計 | 15.80% |

出典: [Wiki: ヤミカラス](https://wikiwiki.jp/poke_sleep/ヤミカラス)（4種食材はほぼ均等＝約1/4ずつ）

### ★4種類プールの内訳（最重要）
- ヤミカラス／ドンカラスの**自分の食材3枠**: 1枠目=めざましコーヒー、2枠目=ワカクサ大豆、3枠目=げきからハーブ。出典: [Wiki: ヤミカラス](https://wikiwiki.jp/poke_sleep/ヤミカラス)
- **きょううんの抽選プール（4種）**: あじわいキノコ／マメミート／ワカクサ大豆／めざましコーヒー。出典: [Wiki: ヤミカラス](https://wikiwiki.jp/poke_sleep/ヤミカラス), [game8](https://game8.jp/pokemonsleep/691898), [ポケらく](https://pokemongo-raku.com/post117569)
- **突合結果**: 自分の3枠のうち「めざましコーヒー」「ワカクサ大豆」の2つはプールに含まれるが、**「げきからハーブ」は含まれない**。代わりに自分の枠にない「あじわいキノコ」「マメミート」の2種が加わっている。
- → **「own3枠＋固定1種」という単純な規則ではない**（下記かいりきバサミ＝クチートの事例と食い違う）。プールはポケモンごとに個別に設定された固定4種リストである可能性が高いが、その決定ロジック（なぜげきからハーブが外れ、あじわいキノコ・マメミートが入るのか）を説明する一次情報（公式・Wiki解説文）は見つからなかった。
- 「全ポケモン共通の固定4種」説は、クチート側のプール（下記）が全く異なる食材構成であることから否定できる。
- **結論: 4種プールの個別リスト自体（何が入っているか）は事実として確定しているが、その内訳が決まる根拠（なぜその4種なのか）は不明。**

### 不明点
- 4種プールの選定ロジック（own3枠との重複関係、非own食材が選ばれる基準）。
- 「まれに」の公式発動確率（上記15.80%はあくまでプレイヤー実測値）。

## 6. かいりきバサミ（食材セレクトS派生・クチート専用）★最重要調査

### Lv別効果量（出典間で食い違いあり）

**(A) ポケらくの表**（本体と同数を追加、と仮定した場合と整合）

| Lv | 通常獲得 | 大成功時合計（追加分） |
|---:|---:|---:|
| 1 | 5 | 10（+5） |
| 2 | 6 | 12（+6） |
| 3 | 8 | 16（+8） |
| 4 | 11 | 22（+11） |
| 5 | 13 | 26（+13） |
| 6 | 16 | 32（+16） |
| 7 | 18 | 36（+18） |

出典: [ポケらく](https://pokemongo-raku.com/post118874)

**(B) game8の表**: Lv1=+5、Lv2=+6、Lv3=+8、**Lv4=+6**（他レベルの法則性から外れるイレギュラー値）、Lv5=+13、Lv6=+16、Lv7=+18。出典: [game8](https://game8.jp/pokemonsleep/692393)

**食い違い**: Lv4の追加個数がポケらく＝+11、game8＝+6で不一致。(A)ポケらくの値のほうが「追加分＝本体と同数」という一貫した法則性・Wiki側の「大成功時は2倍相当」という説明と整合するため、内部矛盾が少ないと考えられるが、確定はできない。両方明記する。

### 仕様メモ・実測発動確率
Wiki「クチート」ページに記載の実測値（サンプル200件、検証記事: https://pokesuri.ogagawa.com/kairikibasami_kenshou/ ）:

| 結果 | 実測割合 |
|---|---:|
| 通常時 | 83.79% |
| 大成功（追加発生）時 | 16.21% |

出典: [Wiki: クチート](https://wikiwiki.jp/poke_sleep/クチート)。追加食材の個数は「本体と同じN個」で合計2N個になる、とのWiki側の説明と(A)の表が整合。

### ★4種類プールの内訳（最重要）
- クチートの**自分の食材3枠**: 1枠目=ピュアなオイル、2枠目=ワカクサコーン、3枠目=あんみんトマト（複数サイト一致）。
- **かいりきバサミの抽選プール（4種）**: ほっこりポテト／ピュアなオイル／あんみんトマト／ワカクサコーン。出典: [game8](https://game8.jp/pokemonsleep/692393), [ポケらく](https://pokemongo-raku.com/post118874), [Wiki: クチート](https://wikiwiki.jp/poke_sleep/クチート)
- **突合結果**: クチートのケースは**「自分の食材3枠（ピュアなオイル・あんみんトマト・ワカクサコーン）＋固定追加食材1種（ほっこりポテト）」**というきれいな「own3＋1」の構成になっている。
- **きょううん（ヤミカラス）とは構成パターンが異なる**（ヤミカラスはown3のうち1つが除外され、非own食材2種が入る）。→ **「own3＋1」ルールは全ポケモン共通ではなく、クチートにはたまたま当てはまるだけ**という可能性が高い。4種内訳はポケモンごとに個別固定されていると考えられるが、公式・Wikiともに一般化されたルールの明言は見当たらず、**確定的な統一法則は不明**。
- Wiki内では「4種はほぼ均等（約25%ずつ）と仮定しても矛盾しない」との検証コメントあり。出典: [Wiki: クチート](https://wikiwiki.jp/poke_sleep/クチート)

### 注意点
- 検索過程で「イシズマイ」「イワパレス」も「かいりきバサミ」持ちという情報がヒットしたが、これはメインシリーズ（剣盾/SV）の特性「かいりきバサミ」（アイテム強奪系特性）との名称混同の可能性が高い。ポケモンスリープのメインスキルとして両者が保有するという一次情報は確認できず、**このリストには含めない**。

### 不明点
- Lv4の追加個数（+11 vs +6）の真値。
- 「ときどき」の公式発動確率（実測16.21%はあくまで参考値）。
- 4種プールの選定ロジックの一般法則。

### 仕様メモ
- **効果アップ条件**: 「チームに異なる種類の(発動者と同じ)タイプのポケモンが多いほど効果量UP」。判定タイミングは**発動時ではなく「メインスキルが発動可能になった時点」のチーム編成**。
- 「異なる種類」の数え方: 同じ進化系統でも別種族なら別カウント（例: ピカチュウとライチュウは別）。ピカチュウの姿違い（ハロウィン等）もそれぞれ別カウント。
- 例外: 「PokémonGO Plus+」連携で出現する特別なピカチュウにはこのスキルの効果がかからない（種類数カウントから除外）。
- ポケモンスリープのタイプは原作の複合タイプの片方のみ採用のため、原作で複合タイプでも本作のタイプが異なれば対象外（例: デルビルは原作ほのお/あくだが本作あく扱いのため「おてつだいブースト(ほのお)」の対象外）。
- **対象**: 「チームのポケモン全員のおてつだいがN回分すぐに完了する」＝**タイプに関係なくチーム全員（発動者含む）が対象**。種類数カウントには該当タイプのポケモンのみ数えるが、恩恵は全員に及ぶ。
- おてつだいサポートSと同様、このスキルで完了したおてつだいはメインスキル発動抽選が起きず、EX/イベントボーナスも無視される。
- 出典はいずれも[Wiki: メインスキル/おてつだいブースト](https://wikiwiki.jp/poke_sleep/メインスキル/おてつだいブースト)

### 不明点
- 特になし（表・条件・対象ともWiki本文で明確に確認できた）。

## 9. ゆびをふる

### Lv別効果量
Wikiの「効果量一覧」テーブルはJavaScript描画（アコーディオン）のため静的取得では中身が確認できず、独自の数値表としては**不明**。ただし仕様として以下が本文に明記されている:

> 「発動するメインスキルのスキルレベルは『ゆびをふる』のスキルレベルに依存する。たとえばスキルレベル5の『ゆびをふる』で『料理パワーアップS』が抽選されると、スキルレベル5の効果が適用される。」

出典: [Wiki: メインスキル/ゆびをふる](https://wikiwiki.jp/poke_sleep/メインスキル/ゆびをふる)

→ 「ゆびをふる」自体は独自の効果量テーブルを持たず、**候補スキルが発動する際に適用されるレベル＝ゆびをふるのLvそのもの**（ただし下記の通り上限は候補スキル側でキャップされる）。

### 仕様メモ
- **候補プール**: Ver.3.7.0時点で26種類のメインスキルが対象（判明分）。
  - **発動確認済（◯）**: エナジーチャージ系、ゆめのかけらゲット系、げんきエール、げんきチャージ、げんきオール、おてつだいサポート、食材ゲット、料理パワーアップ、料理チャンス、おてつだいブースト、つきのひかり、きのみバースト、みかづきのいのり、きょううん、かいりきバサミ、プラス、マイナス、プレゼント、ほっぺすりすり、きのみジュース、ビルドアップ、はどうだん
  - **一部のみ発動（△）**: たくわえる →「はきだすのみ、たくわえた回数0回の効果量」で発動
  - **発動しない（×）明記**: **ゆびをふる自身**、ばけのかわ（未確認による×）、スキルコピー（へんしん／ものまね）、ナイトメア、食材セレクト
  - **未確認（？）**: いやしのはどう、りゅうせいぐん
  - 出典: [Wiki: メインスキル/ゆびをふる](https://wikiwiki.jp/poke_sleep/メインスキル/ゆびをふる)（「対象スキル」表）
- **抽選確率**: 「すべての効果がほぼ均等な割合で発動している」（2023年12月検証）が、**同一カテゴリ内に複数の個別スキル（バリエーション）が存在するためカテゴリ単位で見ると偏りが生じる**（1スキル単位では均等）。
  - カテゴリ別割合（Ver.3.7.0時点・26種類）: エナジー系7種≈27%／食材系6種≈23%／げんき回復系6種≈23%／料理補助系3種≈11%／ゆめのかけらゲット系2種≈8%／特別ポケモン系（おてつだいブースト・みかづきのいのり）2種≈8%
  - 出典: [Wiki: メインスキル/ゆびをふる](https://wikiwiki.jp/poke_sleep/メインスキル/ゆびをふる)
  - 補足: 「一気に2回発動した場合でも1回ごとに再抽選する。稀に2回とも同じスキルが選ばれることもある」（Ver.1.10.0）
- **発動レベル**: 「ゆびをふる」のLvに連動するが、候補スキル側の最大Lvでキャップされる（例: ゆびをふるLv7でもげんきオール(最大Lv6)は最大Lv6で発動、ゆめのかけらゲット(最大Lv8)はゆびをふるの上限Lv7以上では発動できない）。出典: 同上

### 不明点
- 「効果量一覧」テーブルの具体的な中身（JS描画のため未取得）。
- いやしのはどう・りゅうせいぐんの候補該当有無。
- ばけのかわの候補該当有無（Wiki側も「未確認」扱いで断定なし）。

## 10. へんしん（スキルコピー・メタモン専用）

### Lv別効果量
独自の効果量テーブルは持たない。**発動レベル＝発動者（へんしん所持ポケモン）自身のメインスキルレベル**であり、コピーしたスキルはそのレベルの効果量表（例えば「食材ゲットS」ならその表のLv値）で発動する。上限はコピー先スキルの最大Lvでキャップされる（発動者Lvがコピー先の最大Lvを超える場合、コピー先の最大Lvで発動）。出典: [Wiki: メインスキル/スキルコピー/へんしん](https://wikiwiki.jp/poke_sleep/メインスキル/スキルコピー/へんしん)

### 仕様メモ
- **コピー対象の抽選ロジック**: チーム編成中の（自分以外の）ポケモンからランダムに1匹選出し、そのメインスキルを発動。
- **コピー不可・代替効果**: 以下は選出されても「うまく決まらなかった」という表示のあと**エナジーチャージS（固定）**が代わりに発動する。
  - 自分自身と同種のスキルコピー系（へんしん／ものまね）
  - ナイトメア
  - いやしのはどう
  - りゅうせいぐん
  - （ゆびをふるはコピー可能）
- 出典: [Wiki: メインスキル/スキルコピー/へんしん](https://wikiwiki.jp/poke_sleep/メインスキル/スキルコピー/へんしん)（個人ブログ [fireyoshida.com](https://www.fireyoshida.com/entry/2024/12/18/215724) の記述と一致することも確認済み）
- 所持ポケモン: メタモン（No.0132）のみ。

### 不明点
- 独自のLv別効果量表は存在しない（＝コピー先スキルの表を参照する仕様のため「不明」ではなく「該当なし」）。

### きょううん・かいりきバサミへの `ingredient_yield` 宣言案（pool: fixed 化の判定）

**判定: `pool: "fixed"` として個別の4種食材リストを付けることは可能。ただし全ポケモン共通ではなく、ポケモン（または該当スキル所持個体）ごとに異なるリストを持たせる必要がある。**

- ヤミカラス／ドンカラス（きょううん）:
  ```json
  "ingredient_yield": {
    "pool": "fixed",
    "fixed_ingredients": ["あじわいキノコ", "マメミート", "ワカクサ大豆", "めざましコーヒー"],
    "pick": 1,
    "count_by_level": {"1": 5, "2": 6, "3": 8, "4": 11, "5": 13, "6": 16, "7": 18}
  }
  ```
  ※このほかに「まれにゆめのかけらが出る」という食材以外の分岐があるため、`ingredient_yield` だけでは大成功枠（ゆめのかけら）を表現しきれない。別途 `alt_reward` のような分岐フィールドが必要になる可能性がある。

- クチート（かいりきバサミ）:
  ```json
  "ingredient_yield": {
    "pool": "fixed",
    "fixed_ingredients": ["ほっこりポテト", "ピュアなオイル", "あんみんトマト", "ワカクサコーン"],
    "pick": 1,
    "count_by_level": {"1": 5, "2": 6, "3": 8, "4": 11, "5": 13, "6": 16, "7": 18},
    "bonus_on_success": {"chance": "ときどき(実測16.21%、非公式)", "extra_count": "本体と同数(未確定、要Lv4検証)"}
  }
  ```

- **注意**: 上記の `fixed_ingredients` はいずれも「そのスキルを持つ唯一の代表ポケモン」の実測に基づくものであり、**他にきょううん／かいりきバサミ持ちのポケモンが今後追加された場合、同じ4種になるとは限らない**（きょううん・かいりきバサミ自体、現状はヤミカラス系統・クチートのみが所持）。したがって `data/main_skill.json` 側の「カテゴリ単位」の宣言ではなく、`pokemon_master.json` 側の**ポケモン単位**で `fixed_ingredients` を持たせる設計が実態に即している可能性が高い。

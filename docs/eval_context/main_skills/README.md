## この調査で直したもの

- **はどうだん(ゆめのかけらゲットS)** がローカル完全未収録だった。ゆめのかけら（週間エナジー外）と
  カビゴンエナジーを同時に得る複合スキルなのに、かけら側だけ見て価値0で評価していた。
  エナジー直値 200〜2042 を `SKILL_NAME_EFFECT_TABLE` に登録し、`main_skill.json` にもレコード追加。
- **料理チャンスS / ビルドアップの大成功確率は加算**（`max()` で1体代表ではない）。
  各個体が自分のスキルLvの%を持ち寄る形に修正。ビルドアップの%は主効果が食材個数なので
  `GREAT_CHANCE_BONUS_TABLE` に別建て。
- **大成功確率の上限の解釈が誤っていた**。`MAX_GREAT_CHANCE=0.70` を「合計の上限」として使っていたが、
  正しくは **ボーナス側の上限が+70%**。合計は 平日 10%+70%=80% / 日曜 30%+70%=100%。
- **日曜の特典が未実装だった**。基礎大成功確率30%・大成功時エナジー3倍（平日は2倍）・
  なべ容量2倍（※料理パワーアップSの増加分は倍化対象外）を実装。なべ増加分の上限+200 も追加。
- **おてつだいブーストがチーム編成に依存する**（同じタイプの異なる種族が多いほど効果UP）。
  合計回数の行列を `main_skill.json` の `help_boost` に置き、編成のタイプ構成から倍率を掛ける形にした。
  種族のタイプはマスタに列が無いので、きのみのタイプ（`berry.json`）から引いている。
- **きょううん／かいりきバサミの4種プール**を種族側に宣言（`pokemon_master.json` の `ingredient_yield`）。
  ヤミカラス/ドンカラス＝あじわいキノコ・マメミート・ワカクサ大豆・めざましコーヒー、
  クチート＝ほっこりポテト・ピュアなオイル・あんみんトマト・ワカクサコーン。
  **own3枠＋1 のような統一規則では説明できない**（ヤミカラスは自分の枠のげきからハーブが外れ、
  枠に無い2種が入る）。決定ロジックの一次情報は見つからなかった。

## 未解決（数値を作らずに残したもの）

- **みかづきのいのり**: きのみ獲得量が「チーム内の異なるエスパータイプ数」依存の行列で、
  ローカルの逆算値（Lv1で9個）がどの列とも一致しない。テーブルが何体編成を前提にしているかが不明。
- **きのみジュース**: 「ときどき追加できのみジュースを獲得」の分が未評価。
- **オールマイティー(ミュウ)**: アメ数がLv6-8で確率的に増える仕様が未反映。加えて、
  セット中の候補スキル本体の効果を評価に一切加えていない構造的な欠落がある。
- **りゅうせいぐん / ばけのかわ**: Wiki本家が調査中ずっと429で読めず、ゲームエイト＋ポケらく止まり
  （両者の数値は一致し、ローカル値とも一致）。本家での裏取りが宿題。
- **好物きのみ×2・フィールドボーナスがきのみバーストに乗るか**が未確定。
- **大成功の基礎確率 10% / 日曜30%** はWiki側も実測からの推測値。連打時の確率低下も詳細不明。
- サイト間の食い違い（両論併記のまま）: プレゼントLv7（16個 / 17個）、
  かいりきバサミLv4（+11 / +6）、たくわえるの蓄積8〜10回の値、げんきエールSの旧値掲載。

## 方針

「そのスキルが素で何をどれだけ生むか」はマスタ（`data/main_skill.json` / 種族固有は
`data/pokemon_master.json`）の宣言が正本。好物きのみ×2・フィールド・週イベント・チーム構成といった
状況依存の倍率は、編成画面側（`utils/plan_simulation.py` 等）で掛ける。
素の値は `utils/capability.py` の `capability_of()` に集約する。

### 仕様メモ

- 単位: きのみ個数。「合計」欄は自分1体＋チームメイト4体ぶんの合計値（Wiki記載どおり、内訳が自分／チームで分かれている）。
- きのみの個数はメインスキルレベルで固定。**サブスキル「きのみの数S」やフィールドの影響を受けない**（Wikiより）。
- 各ポケモンが持ってくるきのみの獲得エナジーは、**そのポケモンの個体レベルに応じて変化する**（`utils/berry_energy.py`の`lv_energy`と同じ式が適用される前提。ただし本スキル固有の追加係数の明記はWiki上になし）。
- 獲得したきのみは**自動的にカビゴンに回収される**（貯める・手渡しの操作は不要）。
- 好物ボーナス・フィールドのきのみエナジーボーナスについて: Wiki要約では「好物きのみのエナジー増加量アップと発動率アップの恩恵を受ける」という記載が見つかったが、これは一般的な「きのみとくい」フィールドボーナスの説明を指している可能性があり、**本スキル固有に好物×2倍・フィールドボーナスが乗ると明記した一文は確認できなかった**。→ 不明（一般のきのみ獲得ロジックと同じと推測されるが未確定）。
- 獲得するきのみの種類（誰のきのみか）: 明示的な一文（「自分のきのみ＝自分の種族の好物きのみ」等）は本文からは確認できなかった。ただしWiki要約中に「きのみの種類は各ポケモンによって異なり、きのみの基礎エナジーがタイプによって大きく異なる（草タイプはひこうタイプよりおよそ1.25倍高い、との言及あり）」という記述があり、**チームメイトが持ってくるきのみはそのポケモン自身の種族固有のきのみである**ことを示唆している。ただし一次資料の直接引用ではなく要約経由のため、断定はしない＝要確認。
- 所持ポケモンの具体名（トロピウス・カポエラー等）はWebFetch要約に候補名が出たが、実在確認できるポケモン一覧と食い違う可能性が高く、**推測数値・推測固有名を書かない方針のため本ドキュメントには載せない**（不明点リストに記載）。

## 3. ばけのかわ(きのみバースト)（ミミッキュ専用派生）

max_lv: 6（両サイト記載範囲内。それ以上は未掲載）

### 大成功（3倍）の仕様

- 「まれに大成功することがあり、大成功すると合計のきのみ獲得数が**3倍**になる」（ゲームエイトより）。
- 発動確率: **両サイトとも記載なし＝不明**。
- 大成功が発生すると、ミミッキュの見た目が「ばれたすがた（被り物の首が折れた姿）」に変化し、**この状態の間は再度大成功が発生しなくなる**（ゲームエイトより）。
- 「ばれたすがた」から元の「ばけたすがた」に戻る条件: 「睡眠リサーチ、または睡眠データの手動登録を行うこと」（ゲームエイト・ポケらく双方で一致）。
- 大成功の3倍は「合計のきのみ獲得数」に対してかかる、との記述（自分／チームそれぞれに3倍なのか、合計に3倍してから配分し直すのかまでは記載なし＝不明）。

### 仕様メモ

- 「エナジーチャージのように直接エナジーを稼ぐのではなく、チームのポケモンが拾うきのみを集めるのが特徴」（ゲームエイトより、きのみバースト系共通の説明）。
- 編成アドバイスとして「ミミッキュ以外の枠をカビゴンの好きなきのみを拾うポケモンで固めるとよい」という記載があり（ゲームエイトより）、これは**チームメイトが持ってくるきのみがそのポケモン自身の種族固有のきのみであること**を示唆する（＝好物一致のポケモンを編成すればカビゴンの好物ボーナスが乗る、という前提のアドバイスと解釈できる）。ただし「好物ボーナスが乗る」ことそのものを明言した一文はサイト上になく、断定はしない。
- 獲得するきのみの種類そのもの（ミミッキュ自身のきのみが何か）: 明記なし＝不明。
- フィールドのきのみエナジーボーナスが乗るか: 記載なし＝不明。
